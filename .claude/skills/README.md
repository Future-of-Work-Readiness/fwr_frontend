# Repo-local skills

Domain knowledge specific to fwr-frontend. Framework/library patterns belong in
`~/.claude/skills/` instead.

| Skill | Use when |
|---|---|
| `fwr-scoring-model` | changing or explaining any score, pass mark, band, or benchmark |
| `fwr-quiz-flow` | test pages, levels, submit/results hand-off, feedback, new assessment types |
| `fwr-career-onboarding` | onboarding, sector/branch/specialisation, careers, `useCareerStore` |
| `fwr-api-integration` | adding/changing a `hooks/api` hook, API client, auth errors |
| `fwr-dependency-check` | every session start; any upgrade, new dependency, or audit |

Line numbers in these skills were accurate on 2026-11-13. Update a skill in the same commit as
any code change that invalidates it.
